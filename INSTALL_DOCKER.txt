INSTALACIÓN DEL MÓDULO ODOO AI ASSISTANT (Docker)
===============================================

Este documento contiene las instrucciones para instalar el módulo
AI Assistant en un entorno Odoo basado en Docker.

REQUISITOS PREVIOS
------------------
- Servidor Linux con Docker y Docker Compose instalados
- Odoo 17, 18 o 19 via Docker (o se instalará automaticamente)
- Acceso SSH al servidor
- API Key de OpenRouter (https://openrouter.ai/keys)

ESTRUCTURA DEL PROYECTO
-----------------------
odoo17-docker/
├── docker-compose.yml        # Servicios Odoo + PostgreSQL
├── odoo/
│   └── Dockerfile            # Imagen Odoo con dependencias Python
└── custom-addons/
    └── odoo_ai_assistant/    # Módulo AI Assistant

PASO 1: PREPARAR ARCHIVOS
-----------------------
1. Crea la estructura de directorios:
   mkdir -p odoo17-docker/odoo odoo17-docker/custom-addons

2. Copia el módulo:
   cp -r odoo_ai_assistant/ odoo17-docker/custom-addons/odoo_ai_assistant/

3. Crea el Dockerfile en odoo17-docker/odoo/Dockerfile:
   FROM odoo:17
   USER root
    RUN pip install --no-cache-dir \
        'duckduckgo-search>=4.0.0' \
        'nest-asyncio>=1.5.0' \
        'lxml_html_clean'
   USER odoo
   EXPOSE 8069

PASO 2: DOCKER-COMPOSE YML
-------------------------
Crea docker-compose.yml:

version: '3'
services:
  odoo-db:
    image: postgres:16
    container_name: odoo17-db
    restart: unless-stopped
    environment:
      - POSTGRES_USER=odoo
      - POSTGRES_PASSWORD=***      - POSTGRES_DB=odoo
    volumes:
      - odoo-db-data:/var/lib/postgresql/data
    networks:
      - odoo-net

  odoo:
    build: ./odoo
    container_name: odoo17
    restart: unless-stopped
    ports:
      - "8069:8069"
    volumes:
      - odoo-web-data:/var/lib/odoo
      - ./custom-addons:/mnt/extra-addons

    environment:
      - HOST=odoo-db
      - PORT=5432
      - USER=odoo
      - PASSWORD=***    depends_on:
      - odoo-db
    networks:
      - odoo-net

volumes:
  odoo-db-data:
  odoo-web-data:

networks:
  odoo-net:
    driver: bridge

PASO 3: CONSTRUIR Y LEVANTAR
---------------------------
cd odoo17-docker
docker compose build odoo
docker compose up -d

PASO 4: CREAR BASE DE DATOS E INSTALAR MÓDULO
-------------------------------------------
4.1 Ajustar pg_hba.conf (opcional - si hay error de autenticacion):
    docker exec odoo17-db sed -i 's/host all all all scram-sha-256/host all all all trust/' /var/lib/postgresql/data/pg_hba.conf
    docker exec odoo17-db psql -U odoo -c "SELECT pg_reload_conf();"

4.2 Instalar modulos base:
    docker exec odoo17 odoo -d odoo --db_host odoo-db --db_port 5432 --db_user odoo --db_password <tu_password> \
      --addons-path=/mnt/extra-addons,/usr/lib/python3/dist-packages/odoo/addons \
      --stop-after-init -i base

4.3 Instalar AI Assistant:
    docker exec odoo17 odoo -d odoo --db_host odoo-db --db_port 5432 --db_user odoo --db_password <tu_password> \
      --addons-path=/mnt/extra-addons,/usr/lib/python3/dist-packages/odoo/addons \
      --stop-after-init -i odoo_ai_assistant

PASO 5: CONFIGURAR API KEY DE OPENROUTER
---------------------------------------
1. Accede a http://<servidor>:8069
2. Inicia sesion con admin / admin
3. Ve a Ajustes > AI Assistant Settings
4. Ingresa tu API Key de OpenRouter
5. Configura el modelo (openai/gpt-4o-mini por defecto)
6. Guarda la configuracion

Para obtener una API Key:
1. Ve a https://openrouter.ai/keys
2. Crea una nueva API Key
3. Copia la clave y pegala en la configuracion

ACTUALIZAR EL MÓDULO TRAS CAMBIOS
---------------------------------
1. Sincroniza los archivos al servidor:
   rsync -avz -e "ssh -i ~/.ssh/tu_clave" \
     custom-addons/odoo_ai_assistant/ \
     root@<servidor>:/root/odoo17-docker/custom-addons/odoo_ai_assistant/

2. Fija permisos:
   ssh root@<servidor> "find /root/odoo17-docker/custom-addons/odoo_ai_assistant/ -type f -exec chmod 644 {} \;"

3. Actualiza el modulo en Odoo:
   docker exec odoo17 odoo -d odoo --db_host odoo-db --db_port 5432 --db_user odoo --db_password <tu_password> \
     --addons-path=/mnt/extra-addons,/usr/lib/python3/dist-packages/odoo/addons \
     --stop-after-init -u odoo_ai_assistant

4. Limpia cache de assets en DB:
   docker exec odoo17-db psql -U odoo -d odoo -c "DELETE FROM ir_attachment WHERE name LIKE 'web.assets%';"

5. Reinicia Odoo:
   docker compose -f /root/odoo17-docker/docker-compose.yml restart odoo

6. Hard refresh en el navegador (Ctrl+Shift+R)

TROUBLESHOOTING
--------------
El boton no aparece:
1. Verifica que el modulo este instalado (Apps > AI Assistant)
2. Haz hard refresh (Ctrl+Shift+R)
3. Revisa la consola JS (F12) si ves el mensaje ">>> AI FAB Standalone: inicializando"
4. Verifica permisos: los .js deben tener chmod 644

Error de API Key:
1. Verifica que la API Key sea correcta en Ajustes > AI Assistant Settings
2. La clave debe empezar con 'sk-or-'

Error "password authentication failed":
1. Ejecuta en la DB: ALTER USER odoo WITH PASSWORD '<tu_password>';
2. O cambia pg_hba.conf de scram-sha-256 a trust (ver Paso 4.1)

Error "JSON.parse: unexpected character":
- El backend devuelve HTML en vez de JSON. Revisa logs: docker logs odoo17
- Comunmente es error 500 interno (API key invalida, dependencias faltantes)

NOTAS ADICIONALES
-----------------
- Compatible con Odoo 17, 18 y 19
- Requiere acceso a internet para la API de OpenRouter
- Los datos de conversacion se almacenan en la base de datos
- Puerto por defecto: 8069
- Usuario por defecto: admin / admin (configurar en primer inicio)
- El FAB (🤖) aparece en la esquina inferior derecha SOLO despues de iniciar sesion
